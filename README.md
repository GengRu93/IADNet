# IADNet
The code for the paper “IADNet: A neural network for discovering particle interactions from trajectory data”
 
Author: Ru Geng, Yixian Gao, Jian Zu, Hong-Kun Zhang 

Paper: https://www.sciencedirect.com/science/article/abs/pii/S0167278925005342

DOI: https://doi.org/10.1016/j.physd.2025.135057
 
# Usage
a1_train_...py: Train the model

a0_test_...py:   Export the trained weight matrix using the test data

a0_plot_coef.py: Plot a heatmap of the weight matrix
